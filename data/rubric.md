# Rating rubric

This is the rating guide exactly as given to the three raters, with the full description of every score point on all five dimensions (D1 conceptual clarity, D2 grade-appropriateness, D3 pedagogical structure, D4 terminology, D5 language quality). The terminology dimension (D4) shown in the guide is the revised version used for all ratings. The original description, replaced before any rating began, is reproduced at the end.

---

**Give this to each rater along with their spreadsheet. Nothing else.**

---

## What you're doing

You'll read 80 short explanations of school science and maths topics. Some are in English, some in Urdu. Your job is to judge **how well each one teaches**.

Each explanation has a grade level attached — Grade 6, 7, 8, 9 or 10. Judge it **for a student at that grade**, not for yourself.

Score five things from 1 to 5. Descriptions for every score are below. Match the explanation to the description; don't pick a number by feel.

It takes about 2 to 3 hours in total. Do it in sittings of about 20 items. Don't go back and change earlier scores after seeing later ones.

## What you're NOT doing

**You are not checking whether the science or maths is correct.** That's handled separately against the textbooks. If something looks factually wrong, ignore it for scoring and mention it in the Notes column if you like.

You also won't be told which system wrote each explanation. That's deliberate — it keeps your judgement clean.

## Use the whole scale

A 3 means genuinely average. If everything you rate is a 4, the ratings tell us nothing. Some of these are poor. Say so.

---

## The five dimensions

## D1 — Clarity
*Can a student follow this?*

| | |
|---|---|
| **1** | Incoherent or self-contradictory. A student would be more confused after reading it. |
| **2** | Roughly on topic but muddled. The main idea is never stated plainly. |
| **3** | The core idea is there, but buried in padding or awkward ordering. |
| **4** | Clear, with one lapse or a sentence you have to re-read. |
| **5** | Clear on one reading. The central idea lands early and holds. |

## D2 — Grade fit
*Is it pitched right for the stated grade?*

| | |
|---|---|
| **1** | Wildly wrong level — university language for Grade 6, or a Grade 10 topic reduced to one line. |
| **2** | Substantially above or below the grade. |
| **3** | Broadly plausible, but with several words or jumps that don't fit. |
| **4** | Well matched, with one or two terms a student at that grade wouldn't know. |
| **5** | Pitched exactly right. Assumes only what that grade has already covered. |

## D3 — Teaching
*Does it actually teach, or just state?*

| | |
|---|---|
| **1** | A bare definition. No example, no build-up. |
| **2** | An example is promised or gestured at but is absent, generic, or irrelevant. |
| **3** | There's an example, but it decorates rather than illuminates. |
| **4** | Logical build-up plus a working example that supports the idea. |
| **5** | Builds from the familiar to the new, and the example is one a teacher would reuse in class. |

## D4 — Terminology
*Are the technical terms right for this subject?*

**Read this before scoring D4.** In Urdu-medium science teaching, most technical terms are English words written in Urdu script — سرکٹ، رفریکشن، ایٹمک ماس، بائیولوجی. **This is normal and correct. Do not mark it down.** The PCTB Urdu-medium textbooks do exactly this.

In **mathematics**, Urdu terms are more common — تجزی، متغیر، مساوات، قضیہ. That's the norm for maths.

What you're judging is whether the terms are the ones **a Pakistani teacher of that subject would use**.

| | |
|---|---|
| **1** | Unusable. Either so heavily Urdu that a student wouldn't recognise the concept, or collapsed into English sentences / Roman-script Urdu. |
| **2** | Terms are frequently wrong for the subject, or invented. |
| **3** | Mixed. Some terms right, others unfamiliar or unnatural. |
| **4** | Mostly the right terms, with one or two odd choices. |
| **5** | The terminology a teacher of this subject would use, used consistently. |

*For English explanations:* score 5 if every technical term is introduced before it's used and pitched at the grade; 1 if jargon is used undefined and above grade.

## D5 — Language
*Does it read naturally?*

| | |
|---|---|
| **1** | Ungrammatical, machine-translated feel, or unreadable rendering. |
| **2** | Understandable but consistently unnatural. |
| **3** | Serviceable. Recognisably translated in places. |
| **4** | Natural, with occasional stiffness. |
| **5** | Reads as though written by a fluent teacher, in that language, for that audience. |

---

## Special cases

**Empty or unreadable item** — score 1 across the board and note it.

**Broken characters or strange symbols** (letters from another script, `\frac`, stray code) — that's a language problem. It affects D5, and D1 if it makes the meaning unclear.

**Much shorter than expected** — judge what's there. If the shortness means the idea isn't developed, that's D3. If it's short but complete, that's fine.

**An English word inside an Urdu explanation** — see D4 above. Usually correct. Only a problem if it's a whole English sentence, or Urdu written in Roman letters.

---

## Practical

- Type whole numbers 1 to 5. The sheet will reject anything else.
- Notes column is optional. Use it if something is odd and you want to flag it.
- Save the file as you go.
- Send the file back when done. Deadline: **14 August**.

Thank you — this is the part of the study that can't be automated, and the results depend entirely on it.

## Original terminology description (replaced before rating began)

**D4. Terminology handling**

*Urdu items:* 1 — technical terms dumped in English/Roman script throughout despite standard Urdu terms existing; 3 — mixed, some proper Urdu terms, some untranslated; 5 — established Urdu terminology used correctly and consistently, with the English term parenthesised only where that is genuinely standard practice.

*English items:* 1 — jargon used with no definition and beyond grade level; 3 — terms mostly introduced but some assumed; 5 — every technical term introduced before use and at the right level.
